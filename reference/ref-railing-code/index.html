Railing Code — Guardrail & Handrail Requirements

Guardrail vs. Handrail

A guardrail (or guard) is a protective barrier preventing falls from elevated surfaces. A handrail provides graspable support along stairs and ramps. The IRC specifies different requirements for each. Guards are required wherever the walking surface is more than 30" above adjacent grade or floor below. Handrails are required on stairs with 4 or more risers.
