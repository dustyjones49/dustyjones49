Deck Code Requirements — IRC 2021 Reference

Overview

Residential deck construction is governed by the International Residential Code (IRC) Section R507. This section was completely rewritten in the 2015 IRC and updated through 2021. Local jurisdictions may have amendments, but these tables represent the baseline prescriptive code for decks up to 40 square feet above grade and supporting up to 40 psf live load plus 10 psf dead load.
