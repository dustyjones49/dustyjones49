Nail Sizes — Penny Sizes, Lengths & Applications

The Penny System

Nail sizes are traditionally designated by the "penny" system (abbreviated "d", from the Roman denarius). Each penny size corresponds to a specific length. General rule: the penny size was originally the price per 100 nails, but today it simply indicates length. Nails are also classified by type: common, box, finish, and roofing, each with different shank diameters.
