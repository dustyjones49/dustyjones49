Smoke Detector Code — IRC & NFPA 72 Requirements

IRC Section R314 — Smoke Alarms

The International Residential Code requires smoke alarms in specific locations in all new dwelling units and in existing dwellings undergoing renovation. NFPA 72 (National Fire Alarm Code) provides installation standards. The key requirement is that smoke alarms be interconnected so that when one alarms, all alarms in the dwelling sound.

CO Detector Requirements

Carbon monoxide alarms are required outside each sleeping area in dwellings with fuel-burning appliances or attached garages (IRC R315). CO alarms must be listed per UL 2034. New construction requires hardwired CO alarms with battery backup. Combination smoke/CO alarms must be interconnected with the smoke alarm system.
