Brick Sizes — Nominal & Actual Dimensions

How Brick Sizes Work

Brick dimensions include the manufactured unit size plus a standard 3/8" mortar joint. The "nominal" size is the unit size plus one mortar joint spacing on each dimension. Bricks are specified by their "coursing" — the total height of brick plus one mortar bed joint.

Brick Estimating Quick Reference

Multiply wall area (sq ft) by bricks-per-sq-ft from the table above. Add 5—10% for waste and cuts. For veneer walls over wood studs, brick ties are required at minimum one tie per 2.67 sq ft of wall area. Always verify local availability — regional brick sizes vary, and not all types are stocked everywhere.
