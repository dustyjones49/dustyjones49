Insulation R-Value Code — IECC 2021 Requirements

Understanding R-Value

R-value measures thermal resistance — higher numbers mean better insulation. The International Energy Conservation Code (IECC) prescribes minimum R-values for each climate zone (1—8, with 1 being hottest and 8 being coldest). These are prescriptive requirements for new construction and major renovations.
