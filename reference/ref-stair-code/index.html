Stair Code — IRC 2021 Requirements

IRC Stairway Provisions Overview

IRC Section R311.7 governs interior and exterior stairways in one- and two-family dwellings. The code ensures safe, consistent stair geometry. All dimensions below are minimums unless stated as maximums. The "7-11 rule" is a common design heuristic: riser height + tread depth should total between 17" and 18" (ideal: 17.5"), and twice the riser plus tread should be 24" to 25".

Winder & Spiral Stair Exceptions

Winder treads must have minimum 6" depth at narrow end and 10" at 12" walkline. Minimum 10" deep treads required for spiral stairs at the 12" walkline with 6-3/4" minimum at narrow end. Spiral stairs must be 26" minimum width. All winder steps within a flight must have identical tread geometry.
