Mortar Types — M, S, N, O, K Explained

ASTM C270 Mortar Classifications

Mortar is classified by compressive strength using the letters M, S, N, O, and K in descending order of strength. The acronym "MaSoN wOrK" helps remember the order. Standard mortar is a mixture of Portland cement, hydrated lime, and sand. Pre-blended mortars (Type N or Type S) are widely available and ensure consistent proportions.
