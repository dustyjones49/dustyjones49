Egress Window Code — IRC R310 Requirements

What Is an Egress Window?

IRC Section R310 requires every sleeping room (bedroom) and every basement used as habitable space to have at least one operable emergency escape and rescue opening (egress window or door). The opening must open directly to a public way, yard, or court. It must be operable from the inside without tools, keys, or special knowledge.
