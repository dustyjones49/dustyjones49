Frequently Asked Questions

What is a rough opening for a window?
Rough opening is 1/2 inch larger than the window in both directions — so a 36x48 window needs a 36.5x48.5 inch opening. This provides 1/4 in shim space on each side for leveling and squaring. Measure the rough opening, not the old window.
What size header for a 36-inch window?
For a 36 in window: double 2x6 header on a 2x4 wall up to 6 ft span. Use double 2x8 for spans 6-10 ft. Header length = RO width + 3 inches. Trimmer (jack) studs go under each end, king studs run full height beside them.
Rough opening for a 36-inch door?
A standard 36 in prehung door needs a 38 in wide × 82.5 in tall rough opening (2 in wider, 2.5 in taller than door). Exterior doors need 2.5-3 in extra width for shimming. Always check the manufacturer's installation guide.
