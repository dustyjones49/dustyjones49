Frequently Asked Questions

Building code requires 7-8 inch rise and minimum 10 inch run (tread depth). The sweet spot is 7.5 inch rise with 10.5 inch run. Use the comfort formula: 2 × Rise + Run should equal 24-25 inches. Steeper than 8 inch rise feels like a ladder and is uncomfortable.

Use 3 stringers for stairs up to 36 inches wide, 4 stringers for 36-48 inches wide, and space them no more than 16 inches apart. Cut stringers from 2x12 lumber and notch carefully — one bad notch and you'll need to start over with a new board.
