How to Replace HVAC Filter

Overview

Replacing your HVAC filter is the easiest maintenance task you can do to keep your furnace and AC running efficiently. A dirty filter restricts airflow, forces the system to work harder, and spreads dust throughout the house. Replace it every 1–3 months.

Tools & Materials

  • Replacement air filter (check old filter for size, e.g., 16x25x1)
  • Flashlight
  • Permanent marker (to write the date)
  • Phone (to take a photo of the old filter orientation)

Step-by-Step

  1. Turn off the HVAC system. Set the thermostat to OFF or set the mode to OFF. This prevents the system from kicking on while the filter is out and sucking in unfiltered air.
  2. Locate the filter slot. Look for a 1-inch-wide slot on the furnace or air handler, usually between the return air duct and the blower compartment. It may also be behind a return air grille in a wall or ceiling.
  3. Remove the old filter. Slide the old filter out. Note which way the arrow on the filter frame points—this indicates airflow direction. Snap a photo for reference.
  4. Read the old filter size. The dimensions are printed on the cardboard frame. Note the length, width, and depth. If it's unreadable, measure the filter slot.
  5. Choose the right replacement. Buy a filter of the exact same size. MERV 8 is a good balance of filtration and airflow for most homes. MERV 11–13 captures more allergens but may restrict airflow in older systems.
  6. Note the airflow arrow. Look for the arrow printed on the new filter's frame. It must point toward the furnace/air handler (in the direction of airflow).
  7. Insert the new filter. Slide the new filter into the slot with the arrow pointing in the correct direction. It should fit snugly without being forced.
  8. Write the installation date. Use a permanent marker to write today's date on the filter's exposed edge. This reminds you when it was last changed.
  9. Turn the system back on. Set the thermostat back to your preferred mode. Listen for any unusual noise that might indicate the filter was installed wrong.

Pro Tips

Tip 1: Set a recurring calendar reminder to check the filter every month and replace it every 60–90 days at minimum. Homes with pets or allergies should replace monthly.
Tip 2: Buy filters in bulk (3–6 packs) to save money and ensure you always have a replacement ready.
Tip 3: If you hold a dirty filter up to the light and can't see through it, it was long overdue for replacement.
Tip 4: Do not run the system without a filter—even for a few days. Dirt and dust will coat the evaporator coil and blower, reducing efficiency and potentially causing expensive damage.
Tip 5: For return grille filters in the ceiling, use a step ladder. Never stand on furniture or chairs to reach it.
