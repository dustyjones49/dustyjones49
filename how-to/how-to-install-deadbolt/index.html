How to Install a Deadbolt Lock

Overview

Installing a deadbolt provides a significant security upgrade over a doorknob latch alone. A standard deadbolt installation takes about 1 hour on a pre-drilled door, or 2 hours if drilling from scratch. Deadbolts are available in single-cylinder (key outside, thumb turn inside) and double-cylinder (key both sides) configurations, though the IRC typically requires single-cylinder on egress doors.

Tools & Materials

  • Deadbolt kit (includes bolt assembly, exterior cylinder, interior thumb turn, strike plate, screws)
  • Power drill with 2-1/8" hole saw, 1" spade or Forstner bit, and screwdriver bits
  • Chisel set (1" sharp chisel for mortising), hammer
  • Measuring tape, pencil, combination square
  • Center punch (for starting hole saw), masking tape (for marking hole locations)

Step-by-Step

  1. Mark hole locations: Standard deadbolt placement is 6" to 12" above the doorknob. Use the deadbolt template included with the lock, or measure: the center of the face hole should be 2-3/8" or 2-3/4" from the door edge (check your deadbolt's backset). Mark the center of the edge hole at the same height.
  2. Drill the face hole: Use a 2-1/8" hole saw with a pilot drill. Drill from one side until the pilot bit just penetrates, then drill from the other side to prevent splintering. Keep the drill level and perpendicular to the door face.
  3. Drill the edge hole: Using a 1" spade bit or Forstner bit, drill into the door edge at the marked centerline. Go in about 1-1/4" or until you meet the face hole. Keep the bit centered and perpendicular to the door edge. Clean out chips from both holes.
  4. Mortise the faceplate: Insert the bolt assembly, trace around the faceplate with a pencil, and use a sharp 1" chisel to mortise the outline. The mortise depth should equal the faceplate thickness so it sits flush with the door edge. Test-fit and make shallow cuts — it's easier to remove more wood than add it back.
  5. Install the bolt and cylinder: Slide the bolt assembly into the edge hole and screw the faceplate in place. Install the exterior cylinder, aligning the tailpiece through the bolt mechanism. Install the interior thumb turn, securing with the provided machine screws. Test the bolt action before proceeding.
  6. Mark and drill the strike plate: With the deadbolt extended, rub lipstick or chalk on the bolt end, partially close the door, and extend the bolt to mark the jamb. Drill a 1" hole in the jamb at the mark, 1" deep. Mortise the strike plate outline and chisel a recess for both the strike and the bolt's full extension.
  7. Install strike plate and final test: Screw the strike plate to the jamb with 3" screws that bite into the stud behind the jamb — this substantially increases kick-in resistance. Test the deadbolt: it should extend smoothly and fully without rubbing. If it sticks, file or chisel the strike hole slightly until operation is smooth.

Tips & Warnings

  • Use 3" screws on the strike plate into the framing behind the door jamb — standard 3/4" screws only go into the jamb itself and offer minimal security against forced entry.
  • If replacing an existing deadbolt of the same brand/type, you usually only need to change the cylinder — no drilling required.
  • Metal doors require bimetal hole saws and more patient drilling. Let the tool cut at its speed — pushing harder won't speed things up.
  • Do not install a double-cylinder deadbolt on an egress door (any door used for emergency exit) unless local code specifically allows it.
  • Drill from both sides of the door (face hole) to prevent splintering the wood or chipping paint on the exit side.
